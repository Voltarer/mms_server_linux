## Структура проекта
* **`src/`** — Исходный код сервера.
    * `main.c` — Основная логика: опрос портов и обновление модели.
    * `model.icd` — Описание логической модели устройства (SCL).
    * `static_model.c/h` — Файлы, генерируемые из ICD для работы сервера.
* **`lib/`** — Библиотеки и SDK.
    * `libiec61850/` — Стек протоколов МЭК 61850.
    * `realtek/` — Заголовочные файлы и библиотеки Realtek.
* **`build/`** — Папка с готовым бинарным файлом.

## 🛠 Скрипты управления

| Скрипт | Назначение |
| :--- | :--- |
| `./gen.sh` | Превращает XML (`.icd`) в Си-код. Запускать при изменении состава портов или сигналов. |
| `./install.sh` | Скрипт выбора ОС, на которой сейчас работаете |
| `./setup.sh` | Подготовка общей среды разработки (папки и т.д) |
| `./build_MIPS.sh` | Скачивает нужные для работы сервера файлы, собирает библиотеку под MIPS |
| `./build_UBUNTU.sh` | Скачивает нужные для работы сервера файлы, собирает библиотеку под UBUNTU |
| `./choice.sh` | Скрипт выбора ОС, которая требуется |
